# AICA 인사교 — 백오피스 · 프론트오피스

인공지능사관학교 사이트(프론트오피스)와 관리자 페이지(백오피스)를 한 저장소에 모았어요.
받은 그대로 켜면 올린 사람과 같은 화면 · 같은 데이터(관리자 계정 · 게시물 · 올린 사진 · 페이지 임시저장 · 버전 기록)가 보여요.

## 처음 한 번 준비

- **Java 17 이상** — https://adoptium.net (Temurin 17 또는 21)
- **Node.js 18 이상** — https://nodejs.org (LTS)
- 처음 백오피스를 켤 때 인터넷 연결 — Maven과 필요한 부품을 저절로 받아요(몇 분 걸려요)

## 켜기

| | Windows | macOS |
|---|---|---|
| 관리자 페이지 http://127.0.0.1:8080/ | `백오피스.cmd` 더블클릭 | `백오피스.command` 더블클릭(처음 한 번은 오른쪽 클릭 › 열기) |
| 사이트 http://127.0.0.1:4181/ | `프론트오피스.cmd` 더블클릭 | `프론트오피스.command` 더블클릭 |

- 서버가 준비되면 브라우저가 저절로 열려요. 창을 닫으면 꺼져요.
- 로그인 계정은 저장소에 들어 있는 관리자 데이터 그대로예요(처음 관리자 계정은 `백오피스/README.md`).
- 관리자 페이지에서 '사이트에 반영'하거나 게시물을 발행하면 `프론트오피스` 폴더의 파일이 바뀌고, 열어 둔 사이트 화면이 저절로 새로고침돼요.

## 폴더

| 폴더 | 내용 |
|---|---|
| `백오피스/` | 관리자 페이지(Spring Boot). 관리자 데이터는 `백오피스/data` — H2 데이터베이스 · 올린 사진 · 페이지 임시저장 · 반영 전 백업 |
| `프론트오피스/` | 사이트. 페이지마다 폴더가 따로예요: `about` 인사교 알아보기 · `stories` 선배들의 이야기 · `life` 인사교 라이프 · `check` 지원 전 체크 · `home` 홈 · `common` 공통(머리글 · 메뉴 · 바닥글 · 글꼴) |
| `실행 도구/` | 사이트 서버(프론트오피스 실행 파일이 씀) · Claude 배포 링크 만들기 |

## 함께 작업할 때

- 고친 뒤 커밋하고 푸시하면, 다른 사람은 풀(pull)만 하면 같은 내용이 돼요.
- 관리자 데이터베이스(`백오피스/data/backoffice.mv.db`)는 파일 하나라 두 사람의 변경을 합칠 수 없어요. 커밋하기 전에 백오피스 창을 닫고, 여러 사람이 동시에 관리자 페이지에서 고친 뒤 각자 올리지 않도록 순서를 정해 주세요.
- 파일은 받은 사람 컴퓨터에서도 바이트 그대로 같도록 줄바꿈을 바꾸지 않게 해 두었어요(`.gitattributes`).
