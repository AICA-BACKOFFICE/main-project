# AICA 인사교 — 백오피스 · 프론트오피스

인공지능사관학교 사이트(프론트오피스)와 관리자 페이지(백오피스)를 한 저장소에 모았어요.
관리자 데이터는 PostgreSQL에 저장돼요. 클라우드 사이트의 운영 데이터는 별도로 저장돼요.

## 온라인 백오피스

**[고정 주소에서 열기](https://aica-backoffice.tpwls386.chatgpt.site)** — 컴퓨터를 꺼도 접속할 수 있어요.

- 등록된 ChatGPT 계정으로 로그인해요. 다른 관리자는 `관리자 계정 → 신규 등록`에서 이메일과 권한을 등록해 주세요.
- 이 주소에서 편집한 페이지·게시물·미디어는 클라우드에 저장돼요. 로컬 실행 환경과 자동으로 동기화되지는 않아요.
- 배포 소스와 운영 설명은 [`sites/aica-backoffice/`](sites/aica-backoffice/)와 [운영안내](sites/aica-backoffice/운영안내.md)에 있어요.

## 처음 한 번 준비

- **Java 17 이상** — https://adoptium.net (Temurin 17 또는 21 권장)
- **Node.js 18 이상** — https://nodejs.org (LTS)
- **PostgreSQL 16 이상** — https://www.postgresql.org/download/ (설치만 하면 돼요. 설치할 때 정하는 postgres 비밀번호는 백오피스에서 쓰지 않아요)
- 처음 백오피스를 켤 때 인터넷 연결 — Maven과 필요한 부품을 저절로 받아요(몇 분 걸려요)

## 켜기

| | Windows | macOS |
|---|---|---|
| 관리자 페이지 http://127.0.0.1:8080/ | `백오피스.cmd` 더블클릭 | `백오피스.command` 더블클릭(처음 한 번은 오른쪽 클릭 › 열기) |
| 사이트 http://127.0.0.1:4181/ | `프론트오피스.cmd` 더블클릭 | `프론트오피스.command` 더블클릭 |

- 서버가 준비되면 브라우저가 저절로 열려요(그사이 이미 열어 둔 창에서 관리자 화면을 열었으면 새 창은 열지 않아요). 창을 닫으면 꺼져요.
- `백오피스.cmd`는 백오피스 전용 PostgreSQL 서버(`백오피스/data/postgres`, 포트 5433)를 같이 켜요. 처음 켤 때 설치된 PostgreSQL 프로그램으로 그 서버를 만들고, 저장소의 예전 관리자 데이터(`백오피스/data/backoffice.mv.db`, H2)를 옮겨 와요. 컴퓨터에 원래 있던 PostgreSQL 서버(5432)는 건드리지 않아요.
- 로그인 계정은 옮겨 온 관리자 데이터 그대로예요(처음 관리자 계정은 `백오피스/README.md`).
- 관리자 페이지에서 '사이트에 반영'하거나 게시물을 발행하면 열어 둔 사이트 화면이 저절로 새로고침돼요.

## 게시물은 DB에서

사이트 페이지에는 게시물을 적어 두지 않아요. 페이지가 열릴 때 백오피스 공개 API로 PostgreSQL의 지금 내용을 받아 그려요.

| 사이트 | 게시물 | 공개 API | 관리하는 곳 |
|---|---|---|---|
| 선배들의 이야기 | 후기 · 인터뷰 · 프로젝트 · 기수 기록 | `/api/public/stories` | 게시물 관리 › 선배들의 이야기 게시물 관리 |
| 인사교 라이프 | 오늘 점심(식당 · 카페) · 바람 쐬러 갈 곳 | `/api/public/life` | 게시물 관리 › 인사교 라이프 게시물 관리 |
| 지원 전 체크 | 자주 묻는 질문 | `/api/public/faq` | 게시물 관리 › 지원 전 Check FAQ 관리 |

- 사이트 서버(4181)가 `/api/public/…` 요청을 백오피스(8080)로 넘겨요. 페이지는 같은 내용을 `…/api/public/stories.js`처럼 스크립트로 받아요.
- 백오피스가 꺼져 있거나 서버 없이 볼 때를 위해, 백오피스가 저장할 때마다 같은 내용을 사본으로 써 둬요: `stories/js/stories-data.js` · `life/js/life-data.js` · `check/js/faq-data.js`. 사본은 직접 고치지 마세요.
- 그리는 스크립트: `stories/js/stories-render.js` · `life/js/life-render.js` · `check/js/faq-render.js`. 인사교 라이프의 시설 사진은 지금처럼 페이지 파일에 있어요.

## 함께 작업할 때

- **최신 내용 받기**: `최신으로 받기.cmd`(macOS는 `최신으로 받기.command`) 더블클릭 — GitHub에 올라온 최신 내용(코드 · 사이트 · 관리자 데이터)으로 이 폴더를 맞춰요. 필요한 것: [Git](https://git-scm.com)
  - 새 내용이 있으면 백오피스 창을 먼저 닫아 달라고 알려 줘요.
  - 이 컴퓨터에서 바뀐 파일은 지우지 않고 `git stash`에 보관해 둔 뒤 받아요.
- **내가 고친 것 올리기**: 백오피스 창을 닫고 → 바뀐 파일 커밋 → 푸시. 다른 사람은 '최신으로 받기'만 하면 같은 코드 · 사이트가 돼요.
- 관리자 데이터는 이제 각자 컴퓨터의 PostgreSQL에 있어서 GitHub로 같이 가지 않아요. 처음 켤 때만 저장소의 예전 H2 데이터(2026-10-16 기준)를 옮겨 와요. 관리자 페이지에서 고친 게시물은 그 컴퓨터에만 있어요.
- 사이트 파일은 받은 사람 컴퓨터에서도 바이트 그대로 같도록 줄바꿈을 바꾸지 않게 해 두었어요(`.gitattributes`).
