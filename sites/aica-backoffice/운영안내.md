# AICA 백오피스 클라우드 운영

- 고정 주소: https://aica-backoffice.tpwls386.chatgpt.site
- 사이트 ID: `appgprj_6ad0235b68e48191b6bb7f975a92dd68`
- 최고관리자는 최초 연결한 소유자 ChatGPT 계정입니다. 다른 운영자는 `관리자 계정 → 신규 등록`에서 ChatGPT 로그인 이메일과 역할을 등록한 후 접속합니다.
- 비밀번호 변경은 ChatGPT 계정 설정에서 합니다. 기존 로컬 비밀번호는 클라우드로 복사하지 않았습니다.
- 사이트 화면과 관리자 기능은 클라우드 Worker에서 실행됩니다. 페이지·게시물·버전·권한은 D1, 업로드 파일은 R2에 저장됩니다. 로컬 서버와 별도 데이터입니다.
- 초기 페이지는 바탕화면 `새파일/aica-site-preview` 원본과 맞춰 복원한 프론트 파일입니다. 기존 게시물 94개(휴지통 포함), 버전 165개, 이미지 11개를 이전했습니다.
- 페이지의 `사이트에 반영`을 누르면 이 주소의 `/site/` 화면에 적용됩니다. 임시저장과 반영 기록은 클라우드에 남습니다. 변경 충돌 시 새로고침 후 확인하거나 편집기 안내에 따라 처리합니다.
- 게시물을 발행·미게시·휴지통·복원하면 선배들의 이야기 데이터가 다시 생성됩니다. 페이지에서 편집한 내용은 유지합니다.
- 미디어 한도는 이미지 10MB, PDF 20MB, 동영상 200MB입니다. 큰 동영상은 8MiB씩 분할해 R2에 저장합니다.

## 유지보수

`lib/`는 원본 관리 화면의 렌더링과 클라우드 API, `public/`은 기존 디자인·편집기, `db/schema.ts`와 `drizzle/`는 영구 저장소 스키마입니다. Java 프로젝트는 기존 로컬 실행용으로 유지합니다.

`scripts/import-local.py`는 원본 디자인과 화면 템플릿을 가져오는 도구입니다. 다시 실행하면 복사한 정적 파일을 덮어쓰므로 클라우드 전용 변경을 확인한 뒤 사용합니다. `.sites-runtime/import/`의 H2 백업은 이전 확인용이며 소스 저장소와 배포 파일에서 제외됩니다.

로컬 검증은 `scripts/smoke-local.mjs`, `scripts/check-extra-local.mjs`로 실행합니다. 두 스크립트는 `127.0.0.1:5173`의 개발 DB에만 검증 데이터를 만듭니다. 원본 로컬 백오피스와 운영 사이트를 대상으로 실행하지 않습니다.

배포는 Sites 스킬의 source helper로 소스를 저장한 뒤 해당 커밋의 압축 파일을 게시합니다. Windows에서는 설치된 Git Bash가 PATH에 있어야 하고 GNU tar에 `TAR_OPTIONS=--force-local`이 필요합니다. 저장소 인증 정보와 운영 비밀 값은 파일에 기록하지 않습니다.
