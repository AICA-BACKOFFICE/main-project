서포터즈는 이미 게시된 본인 글의 내용도 수정할 수 있다. 글 작성자를 요청 값으로 바꿀 수 없으며 다른 사람의 글은 편집 화면·저장·이전 버전 불러오기/복원에서 모두 차단한다. 게시 상태 변경은 기존 정책대로 최상위 관리자와 관리자에게만 허용한다. 검수·승인 절차는 추가하지 않았다.

영구 삭제는 개별 삭제·선택 삭제·전체 비우기의 모든 경로에서 최상위 관리자만 허용한다. 관리자는 휴지통의 복원 기능을 사용하며 영구 삭제 버튼을 보지 않는다. 공용 미디어 정리·삭제는 관리자도 사용할 수 있다.

서버의 요청·서비스에서 검사하고 화면 메뉴·수정 링크·편집기 상태 선택도 같은 정책을 따른다. 계정 역할 변경·비활성화는 기존 로그인 세션에도 다음 요청부터 반영한다.

## 검증

- Java `RolePermissionsWebTest`: 실제 로그인으로 별도 관리자·서포터즈 계정을 만들어 소유권, 이미 게시된 본인 글 수정, 관리자 영구 삭제 차단, 전체 통계, 사이트·계정 관리, 업로드·미디어 정리, 세션 권한 갱신을 검증한다.
- 클라우드 `scripts/check-roles.mjs`: 운영과 분리된 메모리 D1/R2에서 서로 다른 로그인 ID로 권한을 확인한다. API 요청 68건 및 계정 초기 등록의 중복 실행 방지를 검사한다.
- 실제 ChatGPT 로그인은 등록한 이메일의 소유자가 수행한다. 테스트는 운영 계정의 로그인 자격 증명을 사용하지 않는다.

검증 결과: Spring 전체 테스트 51개(역할 전용 5개 포함), 클라우드 권한 요청 68건과 휴지통 회귀 요청 17건 통과.
